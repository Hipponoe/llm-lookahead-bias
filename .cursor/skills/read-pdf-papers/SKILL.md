# Read PDF Papers

## Instructions

1. **定位文献目录**
   - 默认假设所有 PDF 文献位于用户指定的某个目录（例如 `papers/`、`pdfs/` 或用户在对话中提到的路径）。
   - 如果用户没有说明路径，先简短询问「PDF 文献大致在哪个文件夹（相对当前项目）？」。

2. **列出与筛选 PDF 文件**
   - 使用 `Glob` 工具在给定目录下查找 `*.pdf` 文件。
   - 若文献较多，优先：
     - 只处理用户点名的几篇；
     - 或按文件名排序，先处理前 N 篇（在回复中说明选择规则）。

3. **读取 PDF 内容（使用 Read 工具）**
   - 对于每个目标 PDF，使用 `Read` 工具直接读取文件：
     - `Read` 在 Cursor 中会自动将 PDF 转成文本。
     - 如果返回内容过长，可以通过 `offset` / `limit` 分段读取：
       - 先读取前若干百行，重点抓取题目、作者、摘要和引言；
       - 如需方法或实验细节，再按需要读取后续部分（方法、实验、结论段落）。

4. **抽取论文元信息**
   - 从文本中尽量抽取以下字段（如果缺失就留空，不要硬编）：
     - 题目（Title）
     - 作者（Authors）
     - 发表年份与会议/期刊（Year, Venue）
     - 领域标签（如：金融、经济学、NLP、强化学习等）
   - 若 PDF 文本中存在 BibTeX 或参考条目，可以直接解析并简化为人类可读格式。

5. **结构化总结论文内容**
   - 对每篇论文产生一个结构化小节，建议使用如下模板：

   ```markdown
   ### [论文简称或年份+首作者]

   - **研究问题**：一句话概括论文要回答的核心问题。
   - **数据与场景**：数据来源、时间范围、是否金融/社会科学/仿真等。
   - **方法**：
     - 模型或框架（如：LAP 检验、实体中性化、时间一致性预训练等）
     - 核心技术细节（只写与用户任务相关的部分）
   - **主要发现**：
     - 实证结论（方向 + 大致量级，如果能从文中读到）
   - **与前瞻性偏差的关系**：
     - 该文是诊断/量化偏差，还是提出解决方案？
   - **对当前项目可借鉴点**：
     - 具体可迁移的检验方法、评估协议或算法思想。
   ```

6. **方法与工具标签**
   - 在每篇论文总结末尾，加一行方法标签，便于后续检索，例如：
     - `方法标签：检验类 / 时间一致性模型 / 实体匿名化 / 反事实扰动 / 文本情感基准 / 小模型对比 等`
   - 标签应从论文内容中归纳，而不是随意创造。

7. **批量整理输出格式**
   - 当用户要求对「一批 PDF 文献」进行整理时，优先输出：
     - 按论文分组的详细总结（使用上述模板）；
     - 再输出一个 **方法综述表** 或要点列表，总结：
       - 每类方法的代表性论文；
       - 该类方法的核心思想；
       - 在当前项目（例如 LLM 金融预测中的前瞻性偏差）下是否适用。

8. **面向当前项目的可用性判断**
   - 用户的典型需求是：从文献中筛选出「可以落地到当前项目」的方法。
   - 对每篇论文，至少给出一句结论性判断：
     - **可直接实现**：例如简单的检验（前后窗口对比、匿名化对比）、LAP 类统计检验（在有合适模型和实现的前提下）。
     - **需要大量工程或算力**：例如重新训练时间一致性 LLM、构建大型实时交易基准。
     - **概念性启发为主**：提供写作和论证框架，但不一定在技术上强制实现。

9. **资源与限制的透明说明**
   - 若某些方法在当前环境下难以完全复现（例如需要专门的数据访问、特定开源模型、长时间预训练），在总结中明确点出：
     - 哪些部分可以在论文中「概念引用 + 部分借鉴」；
     - 哪些部分只适合作为 future work 或理论背景。

10. **与现有草稿的衔接**
    - 如果项目中已经有一份手写的文献综述草稿（如 `llm_lookahead_bias_financial_prediction.md`）：
      - 优先保证新的 PDF 总结在概念和符号上与该草稿一致（例如前瞻性偏差、LAP、实体中性化等术语）。
      - 可以在输出中显式标注「这篇文献对应草稿中的哪一节/哪一行」，方便作者合并。

## Examples

- 当用户说：「这个 `papers/` 文件夹里是我收集的前瞻性偏差相关论文，请帮我系统总结一下，并告诉我哪些方法可以直接用在我的 LLM 金融预测项目里。」时：
  1. 使用 `Glob` 找到 `papers/*.pdf`。
  2. 逐篇用 `Read` 读取 PDF，提取题目、摘要、方法和结论。
  3. 按「诊断前瞻性偏差的方法」和「缓解/消除前瞻性偏差的方法」两大类，输出结构化综述。
  4. 对每类方法给出「实现成本 vs 说服审稿人的力度」的主观评估，帮助用户选型。
